# My-Personal-Notes

Aplikasi Catatan Pribadi (Personal Notes App) berbasis React yang dibangun sebagai Proyek Akhir pada kelas **Belajar Membuat Aplikasi Web dengan React** - Dicoding Indonesia.

## Fitur Utama
- **Menampilkan Daftar Catatan:** Memisahkan catatan aktif dan catatan yang diarsipkan.
- **Tambah Catatan Baru:** Menggunakan *controlled component* dengan indikator sisa batas karakter judul (maksimal 50 karakter).
- **Arsipkan Catatan:** Memindahkan catatan antara daftar catatan aktif dan arsip (*archive / unarchive*).
- **Hapus Catatan:** Menghapus catatan secara aman menggunakan pembaruan state reaktif.
- **Pencarian Catatan:** Memfilter catatan secara *real-time* berdasarkan judul catatan.

## Teknologi yang Digunakan
- [React](https://react.dev/)
- [Vite](https://vitejs.dev/)
- Vanilla CSS
